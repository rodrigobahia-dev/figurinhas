    Como usar

    Toque numa figurinha para ver os detalhes. Quando a tarefa estiver feita, cole a figurinha. Nas progressivas, informe quantas unidades já foram feitas.

    No mesmo quadro dá para definir quem é responsável por cada ação. O nome aparece embaixo da figurinha.

    O progresso é compartilhado: toda a equipe vê o mesmo álbum.

    Isso descola todas as figurinhas para toda a equipe. Não dá para desfazer.
